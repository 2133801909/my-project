# 同频 · 校园生活助手（本地演示）

## 打开

先下载最新版「同频校园生活演示-修复版.zip」，解压到一个新文件夹，再双击 `index.html`，使用现代浏览器打开即可。不要继续使用之前解压的旧版文件。当前演示不需要安装依赖或启动服务器。

## 已包含

- 首页概览和演示数据
- 课表周视图、日视图、课程添加/编辑/删除
- 作业、个人安排、完成状态和本地提醒开关
- 课表隐私设置、好友/邀请演示流程
- 主动开启的同系匹配与兴趣筛选
- 校园论坛/项目分享、评论、点赞、举报提示
- 杭州电子科技大学校区名称选择及明确标注的数据占位地图
- JSON 数据导出与本地数据重置

## 演示边界

- 修改仅保存在当前浏览器的 localStorage，不会同步到其他设备。
- 好友、匹配、邀请、论坛、提醒和举报均为本地演示，不会联系真实用户或发送后台通知。
- 新增“演示账号登录 / 注册”和访客入口：仅按昵称在当前浏览器本地保存不同演示资料；不验证身份、密码或学校账号，不联网同步。退出后需再次输入同一昵称进入。此流程不构成真实账号认证；不收集、不保存密码。
- 校区名称参考杭州电子科技大学官网学校简介；校内建筑坐标、地图、室内信息与导航尚未接入。
- 该原型没有杭州电子科技大学官方背书。
