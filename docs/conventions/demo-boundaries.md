# 演示边界

这些边界是产品合同，也是测试与评审依据。突破任何一条都需要用户明确同意 + 新 ADR。

## 数据与网络

- 所有数据只存在当前浏览器的 `localStorage` / `sessionStorage`。
- 应用运行时不发起任何 `fetch`/XHR/WebSocket 请求。
- 唯一外部资源是 Google Fonts 的 CSS `@import`；被拦截时回退到系统字体。
- 不支持跨设备同步、云备份、实时协作。

## 账号

- 仅昵称标识；不收集密码、验证码、学校统一身份账号。
- 不验证身份；“登录成功”不代表真实认证。
- 同一浏览器内昵称大小写不敏感；改名不迁移数据。
- 清除浏览器存储会丢失所有演示账号与聊天。

## 社交

- 好友、申请、邀约、匹配、论坛、举报均为本地模拟。
- 不会通知真实用户，不会发送后台请求，不存在管理员审核。
- 举报只显示提示文案。
- 匹配必须双方主动开启且同院系；这是隐私默认值。

## 媒体

- 图片与语音以 data URL 存在 localStorage；不上传服务器。
- 图片 ≤ 8MB，压缩后 data URL ≤ 3MiB；语音 ≤ 20 秒。
- 录音需要 HTTPS 或 `localhost`；`file://` 下不可用是预期行为。

## 地图

- 只展示五个校区名称。
- 不展示虚构建筑坐标、室内地图、路线或导航。
- 搜索只显示“数据未接入”的说明。
- 文案不得暗示与杭州电子科技大学官方合作。

## 提醒

- “提醒”只是持久化布尔值 + 页面内提示。
- 不使用 Notification API、Service Worker、后台定时器。
- 关闭浏览器后不会收到通知。

## 文案要求

涉及以上能力时必须使用限定词：“演示”“本地”“模拟”“未接入”“不验证”。不要写“已登录学校账号”“实时同步”“精准导航”等误导性描述。
