# ADR 0001：采用 React + TypeScript + Vite

- 状态：已接受
- 日期：2026-11-03

## 背景

旧版是单文件 `app.js`（约 93KB、300 行超长行）+ `innerHTML` 模板 + 单个事件委托 switch。问题：

- 状态、视图、事件、持久化耦合，无法单独测试 UI 行为；
- 字符串模板容易产生 XSS 与失效引用（旧版“添加课程”调用了不存在的函数）；
- 无法增量扩展，新增页面需要复制大段模板。

## 决策

使用 **React 19 + TypeScript + Vite**：

- React 组件化视图与事件绑定；
- TypeScript 严格模式约束状态与 action；
- Vite 提供开发服务器、HMR 与生产构建；
- 不引入组件库/状态库，保持依赖最小。

## 后果

正面：

- 组件与领域逻辑可分别测试；
- 类型检查能捕获 action/字段错误；
- 构建产物可静态托管。

负面：

- 需要 Node.js 与 npm 工具链；
- 首屏需要加载 React 运行时（gzip 后约 108KB）；
- 不再支持“双击 index.html”直接打开，需要静态服务器或 `vite preview`（替代方案见 ADR 0002）。

## 备选方案

- 继续原生 JS + 模板：无法解决可维护性问题。
- Vue/Svelte：同样可行，但团队与现有生态更偏 React。
- Next.js：引入 SSR/服务端，与纯本地演示目标冲突。
